  파이썬을 찾지 못했습니다 — 설치 방법
==========================================================

이 프로그램은 파이썬으로 만들어져 있어서, 파이썬이 있어야 돌아갑니다.


[ 왜 "설치했는데도" 이 안내가 뜨나요 ]

윈도우에는 진짜 파이썬이 아닌 가짜 python.exe 가 들어 있습니다.
실행하면 마이크로소프트 스토어 창만 뜨고 바로 끝나 버립니다.
그래서 겉보기엔 파이썬이 있는 것 같은데 아무것도 동작하지 않습니다.


[ 설치 방법 ]

 1. https://www.python.org/downloads/ 접속

 2. 노란색 큰 버튼 "Download Python 3.x.x" 클릭

 3. 받은 파일을 실행

 4. ★ 가장 중요 ★
    설치 첫 화면 맨 아래
      [v] Add python.exe to PATH
    체크박스를 반드시 켜세요.
    이걸 빼먹으면 설치해도 이 안내가 또 뜹니다.

 5. "Install Now" 클릭

 6. 설치가 끝나면 이 창을 닫고 RUN.bat 을 다시 실행하세요.


[ 그래도 안 될 때 ]

 DIAGNOSE.bat 을 실행하면 어디서 막히는지 알려줍니다.
 결과 파일(data\diagnose_result.txt)을 보내주시면 확인해 드리겠습니다.
